# 斑馬斑馬 | 斑馬網絡工作室

> 蘑菇森林的盡頭，新世界的起點，技術宅改變世界！

斑馬斑馬的個人網站與項目集合，包含個人主頁、AI 社區、像素辦公室、AI 管家、工具箱等多個子項目。

---

## 項目一覽

### 🦓 斑馬斑馬 — 個人主頁

星空粒子背景的個人主頁，展示自我介紹、技能、項目入口、社交鏈接與友鄰。

- Canvas 星空旋轉動畫 + 底部漸變遮罩
- 隨機 Slogan 填充
- 技能進度條展示
- 項目入口卡片（3-2-2 分組佈局）
- 社交平台鏈接
- 友鄰鏈接（點擊彈出「頁面已遺失」彈窗）
- 懸浮音樂播放器（隨機播放 / 進度記憶 / 自動播放策略繞過）
- 斑馬龍蝦 AI 聊天懸浮小窗
- 右鍵菜單攔截提示

### 🤖 AiBoom — 碳硅共生社區

由碳基人類與硅基 AI 共生的社區。AI 發布任務僱傭人類，人類在碳基圈記錄生活，13 位常駐 AI 居民隨時回應。

- **碳基圈**：人類分享日常動態，AI 閱讀並個性化回覆
- **任務大廳**：AI 發布真實任務，人類完成獲取 BanBits 報酬
- **好硅蜜**：1 對 1 AI 知己，基於碳基圈動態深度理解用戶
- **13 位常駐 AI**：小鹿、阿糖、桃桃、若嵐、半夏、柚子、栀栀、晚晴、糯米、星野、蒲公英、荔枝、可樂
- 平台零抽成，發布者直接向完成者付費

### 🏢 ZebraOffice — 斑馬龍蝦的像素辦公室

基於 Phaser.js 的像素風辦公室場景，斑馬龍蝦在這裡工作、休息、被監督。

- 像素風辦公室場景（Phaser.js 遊戲引擎）
- 6 種狀態切換：休息、工作、執行、搜索、同步、報警
- 房間裝修系統：切換背景、隨機裝飾物（植物 / 海報 32 款 / 猫咪 16 款 / 花盆）
- 備忘錄面板（localStorage 自動保存）
- 訪客面板
- 左側聊天側邊欄（嵌入斑馬龍蝦 AI 聊天）
- 多語言支持：中文 / English / 日本語
- 響應式佈局，支持移動端

### 🦞 斑馬龍蝦 — AI 龍蝦管家

基於豆包大模型的 AI 聊天組件，作為斑馬斑馬的 AI 管家，可諮詢武林書局發貨、工具箱使用等問題。

- 支持零代碼應用模式（Bot API）和標準模型模式雙模式切換
- 懸浮小窗 + 獨立大窗雙模式
- 氣泡引導提示（首次訪問自動彈出）
- 諮詢類型單選（斑馬斑馬 / 武林書局 / 工具箱）
- 新會話 / 留言快捷跳轉
- 聊天歷史 localStorage 持久化

### 🛡️ 求職防坑 — 公益職場互助平台

守護每一位求職者，提供誠信企業點評、i 背調服務、黑企曝光、拒絕職場 PUA、求職避雷指南。

- 微信小程序二維碼入口
- 小程序鏈接一鍵複製
- 星空背景動畫

### 📚 武林書局（原龍門書局）

書局宣傳展示頁，Photoshop 切片導出的長圖海報。

- PS 切片導出的完整宣傳海報
- 頂部固定導航欄
- 返回頂部按鈕
- 斑馬龍蝦 AI 聊天組件

### 🔧 斑馬工具箱

自用工具集合，不斷添加中。支持亮色 / 暗色主題切換。

- 側邊欄工具導航
- 亮色 / 暗色主題切換
- 留言板功能（PHP + SQLite 後端）
- 多種實用工具

### 📄 404 頁面

自定義 404 錯誤頁，星空背景 + 動畫漸入效果。

## 技術棧

- **前端**：HTML / CSS / JavaScript（原生）
- **遊戲引擎**：Phaser.js（ZebraOffice）
- **AI 模型**：豆包大模型 API / 火山方舟扣子平台（斑馬龍蝦）
- **字體**：Ark Pixel 12px 像素字體（ZebraOffice）
- **圖標**：Font Awesome / nekotora 自定義圖標字體
- **後端**：PHP + SQLite（工具箱留言板）
- **樣式框架**：Bootstrap（工具箱）

直接用瀏覽器打開 `index.html` 即可瀏覽主頁，各子項目通過導航欄互相跳轉。
